# Calculator

A simple calculator built with HTML, CSS, and JavaScript.

This project started with my curiosity to understand how software works behind the scenes and how to make applications more reliable through testing and experimentation.

### Tech Stack
- HTML, CSS, JavaScript
- Node.js, npm, Vitest
- Git, GitHub Actions

### Getting Started

```bash
git clone https://github.com/YOUR_USERNAME/calculator-devops.git
cd calculator-devops
npm install
npm test
```

Open `index.html` in your browser to use the calculator.

### Learning Goals

Exploring automated testing, debugging, version control, and continuous integration through hands-on practice.

*Built out of curiosity. Improved through experimentation.*
